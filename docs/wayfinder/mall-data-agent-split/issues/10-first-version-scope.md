# 10: 首版能力清单与卡片形态

Type: grilling
Status: resolved
Blocked by: 08, 09

## Question

HITL 拍板：data agent 首版做哪几个分析场景与呈现形态——

- 候选场景：销量 Top/趋势（merchant_order_items 聚合）、差评榜与情感分布（merchant_product_reviews / product_reviews）、退货退款率与售后工单（after_sale_tickets + 订单状态）、会话指标/客服负载（session_metrics）；可增删；
- 每场景的卡片形态：表格为主 or 简单图表（图表库选型方向即可，视觉细节留给实现期）；
- 入口与快捷问题胶囊（死按钮禁令同样适用：每个胶囊背后必须有真能力）；
- 指标口径只列维度骨架（图谱期决议：具体口径实现期对着真实数据定）。

产出：首版能力清单 + 每能力的一句话口径骨架 + 明确不做清单，进 spec 第②部分。

## Answer

决议日期 2026-09-17，用户全盘采纳推荐（Q1–Q5）。

### D1 首版指标族 = 四族全收、每族做薄（广度优先验证问句分布）

1. **销售排行族**：现有 5 指标（gmv / volume / gross_profit / margin_rate / stock_risk）+ 补反向方向（「卖得最差」→ direction=ASC）+ 时间窗 + 品类过滤——query_product_ranking 迁移到新执行器的直接受益者（落实 09-D4-③）；
2. **评价族**（新注册）：差评榜（rating≤2 排行）、评分分布（星级计数）——数据源 merchant_product_reviews；
3. **退货退款族**（新注册）：退款率排行、退款金额 top、售后工单状态分布——after_sale_tickets + 订单状态；
4. **会话客服族**（最薄，2 指标）：会话量趋势、AI 自动解决率——session_metrics 真算（与平台大盘同源口径）。

新指标注册顺序（落实 08-D3-④）：销售族=迁移现有，评价族 → 退货族 → 会话族依次登记。

### D2 卡片形态与图表库

- 表格为主基座（复用现有卡片基建）；仅两类配图：趋势→折线图、分布/占比→条形图；
- 图表库定 **ECharts**（echarts-for-react）——功能覆盖广、与 DataAgent 参照一致；视觉细节留给 16 号产品原型。

### D3 快捷问题胶囊（六个，全部背后有真能力，死按钮禁令）

「本月销量 Top10」「卖得最差的商品」「差评最多的 SKU」「近 30 天退款率」「售后工单概况」「客服负载概况」——每族 1–2 个，一一对应 D1 清单。

### D4 口径骨架（细则实现期对真实数据定）

| 能力 | 口径骨架 |
|---|---|
| 销售 5 指标排行 | 有效订单聚合（排除 REFUNDED/CANCELLED，沿用现口径），支持时间窗/品类/方向 |
| 差评榜/评分分布 | 商户库真实评价，差评=rating≤2，分布按星级计数 |
| 退款率/退款金额 | 退款单数÷有效单数；金额按实际退款额聚合 |
| 会话量/自动解决率 | session_metrics 同源真算，与平台大盘口径一致 |

### D5 首版明确不做

对比类（环比/同比）、归因类（「为什么退货变多」）、跨实体多跳、数据导出（归 14 号票另议）——均留二期演化缝评估。
