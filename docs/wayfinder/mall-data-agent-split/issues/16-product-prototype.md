## Answer

决议日期 2026-09-18，用户经原型多轮 react 后定稿（「嗯 继续」收口）。

### 产品形态定稿（进 spec 第④部分）

- **全局悬浮 agent**：后台任意路由右下角可唤起（参照 storefront FloatingChatWidget 模式），上下文徽标 = 当前路由 + 选中数据实时联动；面板内可对话、可跳全屏。
- **数据分析页 = 全屏工作台**：多轮深聊 / 多卡片回答 / 会话历史 / 报告生成；**与悬浮共享同一条会话线程**（悬浮「全屏对话」即展开态，上下文不丢）。菜单保留直达入口。
- **模块化菜单**：数据（数据分析/我的报告）、商品（列表/分类）、订单（履约）、用户（客户）、运营（优惠活动·规划位）、系统（权限管理）——每模块自带子路由。
- **实体对比（v1 能力）**：任意列表页勾选 ≥2 实体 → 对比卡；呈现 = 并排指标表 + 雷达图（一次回答多卡）；对比维度 = 实体属性 + 已注册指标闭集，随权限过滤；机制 = 实体 IN 过滤 + GROUP BY 实体的单次模板查询。
- **报告归口**：agent 生成的报告统一进「我的报告」（14-D4），对话流保留生成瞬间卡片作过程记录。
- **权限卡**：三档角色（老板/运营/仓储）呈现于权限管理页；**优惠活动屏为规划占位，不放可点按钮**（死按钮禁令，待 20 号）。
