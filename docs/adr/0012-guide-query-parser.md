# ADR-0012: guide 侧货架词典解析器(词元产出从「分块偶然切分」升格为「整句结构化解析」)

日期: 2026-10-09。状态: **已采纳**(用户裁决,同日;grilling 两轮收官,全部决策点已裁决,见「决策」各条括注)。
上位关系: 无被取代 ADR;与 [ADR-0010](0010-tiered-trust-architecture.md) 无依赖(analytics L0 词林是同哲学不同域的先例,非本 ADR 上位)。实弹背景: `test_guide_quantified_family_noun.py` 症状链三连(0927 搭配补脚 / 1001 衣族别名 / 1009 黏词兜底)。

## 背景

1. **同族实弹三连发病,每次修的都是措辞形状**:「搭配一套…装备和衣服」(0927 OUTFIT_RE 补脚)→「推荐衣服和背包」(1001 衣族别名,精确键相等)→「推荐**一些**衣服和装备」(1009 黏词兜底,包含式扫描)。根因结构未动:词元产出依赖「wrapper 剥词 → 按分隔符分块 → 逐块精确/包含匹配别名册」,**词素匹配的命运被分块边界随机决定**——第四种措辞形状(如「保暖点的外套」,「外套」无别名键)随时再发病。
2. **业界对照(2026-10 检索)**:美团 Query 理解四件套(实体识别&实体链接/改写/意图)、Amazon QUEEN、Instacart LLM QU 共同形状 = **检索前置的 Query Understanding 管线**:品类中心词从整句按词典/模型抽出为结构化槽位,修饰语天然剥离——黏词类缺陷在该形状下结构性不存在。本仓 analytics 侧 L0 词林(yaml 单一事实源 + 导入校验 + 最长匹配,`l0_lexicon.py`)已是同哲学;guide 侧的检索词产出仍停留在分块层。
3. **炸面盘点**(2026-10-09 查证):`search_products` 四路调用方——guide 主检索(`recommendation.py:30/51/104`)、cart 销量榜加购反问(`cart/actions.py:530`)、LLM 兜底工具 `searchProducts`(`ecommerce_tools.py:413`)、`compare_products`(`catalog.py:873` 内部再调);gateway SPI 经 A8 共享面直接消费 `search_terms`/`catalog_match`(`merchant_domain.py:14,359-369`),不走 `search_products`。性能:词典层纯 Python 扫描微秒级(51 wrapper + 26 词素),真实成本中心是轮转 SQL 往返(每死词元白打一枪,「天气冷了」「外出游玩」今天各废一次查询)。

## 决策

1. **新增 `tools_registry/mall/query_parser.py` 纯函数解析器**,插入点 = `search_products` 内部,**四路调用方统一换血**(裁决 Q7a:同一货架不该有两套检索语义,延续 A8 收 `catalog_match` 的同一纪律);gateway SPI 共享面不动(裁决 Q1a,SPI 对齐列非目标)。`AI_GUIDE_PARSER=off` 逐字节回退旧路(裁决 Q2)。
2. **槽位模型 v1**:解析产出 `{legs, modifiers, dropped}` 三槽——
   - `legs`:检索脚,= **词典命中词素(经别名册展开,衣服→衬衫/T恤/夹克/冲锋衣/羽绒/裤/POLO)∪ 分块清洗链存活残留**(「装备」「联名背包」等不在册词保留为脚,recall 不缩——品类列宽名「露营装备」靠 ILIKE 子串命中,精确 category 过滤明确不做);去重保序。
   - `modifiers`:场景/修饰槽(「天气冷了」「外出游玩」族),**只剥不扬**——不进 legs 不参与排序(裁决 Q3a,排序语义另立议题),槽位保留给未来排序权重不欠债。修饰册沿用核实纪律:只收核实过的非商品词,存疑一律留 legs(今天它们也只是废脚,无害)。
   - `dropped`:仅喂 diff 日志,不进任何消费面。
   - 整句**最长匹配**在分块之前跑:词素在句不在块,分块边界不再决定词素命运(本次架构升格的本体)。
3. **品类词典动态跟库**(裁决 Q8a):品类词运行时经 `get_shelf_overview()` 取(9 品类,商户后台改品类/上新自动跟),同回合复用、不建缓存(L4 双空时本就同调;主路 +1 次轻量 SQL,可接受);库不可达 → 品类册空、静态册照常,整体检索链语义不变。**词素/别名册原地不动**(`_TERM_STEM_ALIASES` 等,已钉测试;迁 yaml 是纯仪式,不做)。与 analytics 的差异是有意的:L0 品类 9 值是语义模型资产(ADR-0010 产物,钉 yaml),货架品类是**商户运营数据**,钉死等于把商户自治收归代码。
4. **行为保留契约**(裁决 Q4a,验收线):两族交错在场、诚实空+品类盘点、缺族注记、数量语义 limit、颜色 SKU 级过滤、OFF_SALE status 闸、轮转 rank 交错合并语义——全部不动。**既有测试册全绿 = 合同**:任何用例翻红按「解析器违约」处理(修解析器,不改断言;`test_merchant_catalog_reach.py` off-sale 例外的改钉已留痕在案)。`AI_GUIDE_PARSER=off` 下全量册逐字节绿。
5. **OUTFIT_RE 搭配补脚留任**(裁决 Q5a):解析器管「已收录词素的黏词变形」,补脚管「货架真缺族的诚实注记」——纵深防御各管一段,不添新维护面。
6. **上线与观察**(裁决 Q2):`AI_GUIDE_PARSER` 默认 on(消费点 `os.environ` 即时读,对齐 analytics `AI_METRIC_HEAD`/`AI_T1_COMPOSE` 先例 —— 便于测试按用例切换,刻意不入 config.py 导入期 Settings);diff 日志 `[GuideParser]` 前缀(legacy terms vs parser legs 差异时打印,`AI_GUIDE_PARSER_DIFF` 默认 1)——纯函数无统计不确定性,不做 metric_head 式三态 shadow,diff 的唯一价值是观察期回流词典缺口,期满拆默认值随提交留痕。
7. **降级纪律**:解析器任何异常 try/except 降级旧路(「无异常冷启动」准则);解析零产出 → **整句回退旧词元路、严禁部分混搭**(全修饰句/未收录口语保持今日行为,含 L2/L4 对死词元的既有兜底)。注意 off 回退的是**含 1009 黏词兜底**的旧词元路 —— 包含式别名展开属旧路资产,off 只撤解析器不撤 1009(off 态两族仍在场,钉面 `test_guide_query_parser.py::test_off_switch_reverts_to_legacy_terms`)。

## 否决项(从零推演留档)

| 项 | 理由 |
|---|---|
| 现状 whack-a-mole(逐措辞打补丁) | 同族实弹已三连;补丁速率永远追不上口语变化速率 |
| 中文词法小模型 NER(LAC/HanLP) | 引入模型依赖与不确定性,与本仓「显式小词表、确定性可钉面」哲学相悖;词典规模(9 品类 + 26 词素)远未到词典法天花板 |
| LLM 改写前置化(Instacart/QUEEN 路线) | 每句过 LLM 的延迟/成本不可行;2025 前沿(RL 蒸馏 MiniELM、QUEEN)共同趋势恰是「蒸馏掉逐句 LLM」——反证。本仓 L4 改写(词表锚定+2s 超时+双空兜底)已在正确位置 |
| 大词林/外部同义词库 | 会把不属本货架的品类拉进 OR 面,违背「查无必须诚实空、不跨目录补货」红线 |
| 三态 shadow 灰度 | shadow 是给「不确定对不对」的统计层用的;纯函数由测试册钉死,三态是维护税 |
| 品类词钉 yaml(对齐 L0 形制) | 货架品类是商户运营数据非语义模型资产,钉死必漂移;动态性的代价由「同回合复用+失败降级+密封货架测试」三件套偿付 |
| 槽位 → 精确 category 过滤 | 品类列是宽生活方式名(「露营装备」),用户说「背包」品类列是「背包收纳」,exact 必漏;ILIKE 四列 recall 面维持 |

## 非目标(后续独立议题,本 ADR 不裁决)

排序语义(min_price ASC → 场景词 boost,`modifiers` 槽已留缝)/ 混合召回并行化(dense+sparse 融合,牵动「词元命中即不语义」与评测定标)/ gateway SPI 对齐(契约冻结面,独立提交)/ 词族之家词表重寄居(`_TERM_STEM_ALIASES` 与 `CLOTHING_ANCHOR_FAMILY` 双册并存是已声明的现状,收敛列远期)/ wrapper 词表迁 yaml。

## 后果

- 主路 +1 次 `get_shelf_overview` SQL/回合;轮转 SQL 只对活脚发射(「天气冷了」类死块不再白打一枪,N 下降)。
- 黏词措辞(「一些衣服」「保暖裤子」「防水冲锋衣」—— 黏在**在册**词素/品类上)由块内最长匹配结构性接住;「外套」类不在册词素**不入册**(种子货架零词面,核实纪律),待货架实存后随别名册收录。验收 = 新册 `tests/test_guide_query_parser.py` 16 例(纯函数:黏词变体/品类册命中/修饰剥除/最长优先/浏览形;接线:两族在场/活脚 2 查/off 态 4 查互证/零产出回退诚实空/动态品类词典)。
- 词素册仍手册核实制,增长靠实弹回流(diff 观察期是唯一的自动缺口探测器);解析器不是 NLU,超出词典的口语仍由 L2 语义/L4 改写兜底——三层分工写进规则文档。
- 实施批次(裁决通过后):解析器 + 开关 + diff + 新册 + 既有册全绿 + `.claude/rules/tools-registry.md` §1.1 补记,一批提交;SPI 对齐、排序语义另行立项。
