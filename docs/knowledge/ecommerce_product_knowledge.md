# 官方综合商城商品知识与养护指南

## 棉质与针织服装面料特性及洗护(慢跑裤/T恤/衬衫)
1. 420g 重磅毛圈棉属于高克重针织面料，克重越高手感越厚实挺括、不易透；首次洗涤建议冷水单独进行，深色衣物存在轻微浮色属正常现象。
2. 毛圈棉/纯棉制品机洗请装入洗衣袋并选择轻柔档，与含拉链、魔术贴的衣物分开洗涤，避免勾丝起球；领口罗纹受力变形后可用温水浸润后手工整形晾干恢复。
3. 抽绳束脚款洗涤前请系好抽绳并束紧裤脚，防止绳带在机洗中抽出卡入滚筒；罗纹收口忌暴晒，阴干可延缓弹性老化。
4. 精梳棉 T 恤印染图案请翻面洗涤、翻面晾晒，避免图案摩擦脱落；亚麻混纺衬衫建议 40℃ 以下水温手洗，半干时悬挂整形可减少熨烫。
5. 棉质衣物收纳前务必洗净晾透，柜内放置樟木条或干燥剂防潮防蛀；白色棉制品避免与牛仔类深色衣物同洗造成染色。

## 功能性外套洗护与收纳(三合一冲锋衣/软壳/羽绒)
1. 三合一压胶冲锋衣严禁机洗搅洗、烘干与使用柔顺剂：中性洗涤剂 30℃ 温水中性手洗、软刷轻刷污渍、悬挂阴干；压胶条忌熨烫与尖锐物刮擦。
2. 冲锋衣表面防泼水衰减属正常现象，低温烘热或专业防泼水剂喷涂可恢复；开胶、压胶脱落请勿自行粘贴，返厂重新压胶可恢复防水。
3. 三合一内胆(抓绒/羽绒)与外壳分洗：抓绒可机洗轻柔档，羽绒内胆须拉紧全部拉链、中性洗涤剂手洗，洗后拍打让羽绒蓬松复原再阴干。
4. 羽绒制品长期收纳须使用透气防尘袋悬挂存放，严禁压缩袋长期压缩导致羽绒纤维疲劳回弹力下降；换季收纳前彻底晾干防止霉变异味。
5. 软壳面料外层忌高频机洗，局部污渍湿布擦拭即可；接触过汗水与雨水的功能性外套应尽快清洗晾干，盐分与水渍会加速涂层老化。

## 鞋靴养护(跑步鞋/徒步鞋/老爹鞋)
1. Vibram 橡胶大底忌接触高温与尖锐岩石长时间摩擦；鞋面网布与合成革用软毛刷蘸中性清洁剂轻刷，严禁整机浸泡与洗衣机搅洗。
2. 鞋垫与鞋带取出分开清洗，洗后鞋内塞入纸巾吸湿定型、阴干 48 小时以上再穿；暴晒会导致胶水层开胶与鞋面发黄。
3. 徒步登山鞋穿着后及时清理大底齿缝中的碎石泥沙，长期不清理会加速大底磨损并影响抓地；防水膜款避免用硬刷刷鞋面接缝。
4. 建议备有两双运动鞋轮换穿着，鞋内湿度需 24 小时以上自然散发，长期连续穿着会加速中底泡棉塌陷与菌味滋生。

## 背包与配件养护(徒步背包/胸包/腰包)
1. Cordura/尼龙面料背包清洗用湿布擦拭或中性洗涤剂冷水手洗，严禁机洗脱水与高温烘干——涂层与织带承重结构遇高温会变形。
2. 背负系统(肩带/腰垫/背板)海绵吸汗后须拆洗晾干，汗盐结晶会让织带硬化磨肩；长期收纳前清空所有隔层并拉开全部拉链透气。
3. 金属扣具(UTX/Duraflex/Fidlock 磁吸)避免与钥匙等硬物长期同袋摩擦刮花；磁吸扣远离强磁场环境以防消磁失灵。

## 露营装备使用与存放(帐篷/睡袋)
1. 帐篷使用后无论是否淋雨都必须完全晾干再收纳，潮湿收纳 3 天以上即可能产生涂层水解与霉斑——这是帐篷报废的第一大原因。
2. 帐篷清洗只可用清水冲洗或湿布擦拭，严禁使用洗涤剂：洗涤剂会破坏硅涂层面料的防水结构；地钉泥沙清理干净防锈。
3. 睡袋(棉睡袋/羽绒睡袋)每次使用后晾晒通风 2 小时再收纳，长期收纳展开悬挂；压缩存放仅限短途运输。
4. 帐篷拉链卡滞请涂抹拉链专用蜡或铅笔芯润滑，严禁硬拉——野外面拉链损坏是最高频的非质量问题报修。

## 选购与尺码建议
1. 功能性外套(冲锋衣/软壳)建议内层叠穿预留一码余量；修身版型与宽松版型的同尺码胸围差可达 6-8cm，下单前请以商品详情的尺码表为准。
2. 跑步鞋选择以脚长(mm)对应鞋码为准，傍晚脚部微胀时测量最准确；登山徒步鞋建议比日常鞋大半码，预留下坡时脚趾前冲空间。
3. 背包容量选择参考：单日徒步 20-30L、两日轻装 38-45L、多日重装 50L 以上；容量之外更应关注背负系统的承重分区与腰扣结构。
4. 运动配件(护膝/水壶/营地灯)购买前请确认与主装备的兼容性：护膝围尺码、水壶口径与水壶袋、营地灯挂点口径均可咨询客服核对。

## 在售主力款尺码与版型速查
1. Vibram 复古解构老爹鞋鞋楦偏宽，常规脚型按日常运动鞋码选购：40码=250mm、41码=255mm、42码=260mm、43码=265mm。
2. 三合一硬壳冲锋衣为冬季叠穿设计，建议比贴身衣物大一码：M=170/88A、L=175/92A、XL=180/96A。
3. Cordura 机能工装裤按实际腰围选码：M=30腰、L=32腰、XL=34腰；宽松锥形慢跑裤尺码常规，束脚罗纹自带弹性余量。
4. 420g 重磅毛圈棉慢跑裤面料预缩水处理，机洗后长度变化极小；偏好利落落地感选常规码、偏好堆叠感可大一码。
