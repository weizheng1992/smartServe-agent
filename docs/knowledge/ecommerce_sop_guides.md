# 电商主站系统操作 SOP 指南

## 退换货与退款政策
1. 自签收之日起 7 天内支持无理由退换货，退回商品须吊牌完整、未经洗涤且不影响二次销售；非质量问题退货运费由买家承担。
2. 开线、断底、防水失效等质量问题，15 天内免费换新并报销运费；质量问题经核实后运费由商家承担。
3. 退款在仓库质检入库后 48 小时内按原支付路径退回，优惠券与积分同步回退。
4. 定制类与预售商品不支持无理由退货，页面会单独标注；拆封的个人护理类商品因卫生原因不支持退货。

## 电子发票开具与改抬头步骤
1. 打开网页控制台或 App 进入【我的订单】。
2. 点击【申请发票】，选择个人抬头或企业抬头并输入统一社会信用代码。
3. 系统会在 5 分钟内自动生成 PDF 电子发票并发送至您的注册邮箱。

## 订单修改地址与改派 SOP
1. 未发货状态：可在聊天框中直接发送“修改地址为：新地址”，提供订单号后系统自动更新。
2. 已发货状态：系统无法直接拦截修改包裹走向。如有需求请联系人工客服协调，是否支持改派以物流商实际答复为准。
