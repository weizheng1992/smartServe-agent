# 电商主站系统操作 SOP 指南

## 电子发票开具与改抬头步骤
1. 打开网页控制台或 App 进入【我的订单】。
2. 点击【申请发票】，选择个人抬头或企业抬头并输入统一社会信用代码。
3. 系统会在 5 分钟内自动生成 PDF 电子发票并发送至您的注册邮箱。

## 订单修改地址与改派 SOP
1. 未发货状态：可在聊天框中直接发送“修改地址为：新地址”触发系统自动更新。
2. 已发货状态：系统会自动联系快递员（顺丰/圆通）进行改派，由此产生的转寄费用由买家自理。
