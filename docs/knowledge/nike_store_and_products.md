# Nike 淮海中路旗舰店与商品保养指南

## 门店营业时间与地址
Nike 淮海中路旗舰店营业时间为每日 10:00 至 22:00。地址：上海市黄浦区淮海中路 816 号。
店内提供现场 3D 步态足型诊断测量、个性化烫印定制以及专业跑鞋试跑体验服务。

## GORE-TEX 防水越野跑鞋洗涤与保养说明
1. 刷洗前请先拆下鞋带与鞋垫。
2. 使用 30℃ 以下温水配合中性洗涤剂与软毛刷轻轻刷洗网面，严禁使用强碱性洗衣粉。
3. 洗净后置于阴凉通风处自然风干，切勿暴晒或使用烘干机，以免导致 GORE-TEX 防水膜开裂。
