# 意图分析 Gen-3 裁决 spec (Intent Analysis Gen-3 Verdict Spec)

**Status:** 待评审(synthesized 2026-09-27)
**来源:** wayfinder 图 `.scratch/intent-analysis-gen3/`——四张研究票(方法调研/点火审计/词表散射清单/现代方法外调)+ 三张裁决票(词表之家/planner 边界/级联与影子)合成;证据细节在票不在本 spec。
**范围:** 客服意图判定全域 = `triage/` 仲裁级联(9 Stage)+ planner 快轨 + skills 层词表触手;`analytics/` 意图层仅作方法论对照,不裁不动。

## 0. 总纲

**主尺 = 变更局部性**:加一个新意图/新词族只改一处(可演示验收见 §5)。**底线 = 判定质量不回退**(§7 四层基线钉住)。代码体量只作参考信号。

**三红线**(每期验收逐项自检):

1. **延迟不回退**——咨询直答 3-4 次→1 次、快轨零 LLM 的既得收益不动;
2. **契约面不动**——`intent_logs` 落库口径、SSE 线格式冻结;补观测只增列/新表,不改写;
3. **渐进可回退**——每期独立上线、独立回滚,纯收敛期与行为变更期分开。

**方法论底盘**(现代方法外调结论):现有「多提议者 + 置信门控 + LLM 仲裁」已是业界主流形态。Gen-3 不引入新范式,裁决的是**接管档位与资产归位**。Gen-2 终局权原则原样继承为红线:**正则建议、LLM 仲裁**——任何便宜层不得独自终局。

## 1. 域 A — 词表之家(结论:intent_registry.py 扩容为单一之家)

- **家** = `triage/intent_registry.py`(已是 triage/skills/graph 三包共同上游的真叶模块,仅依赖 re/dataclasses),docstring 正名「意图判定资产注册表」。不开第二真相源。
- **组织形状**:模块级家族常量(frozenset 源)+ 按消费面程序化派生 RE;IntentSpec 只引用不拥有。**收录判据:消费方 ≥2 才入册**;单消费方词表留技能本地,但同族必须派生、禁手抄。
- **迁移范围**:散射 Top 榜 #1–#9(词条族 N≥5,加购动词 N≈12 / 下单结算 N≈10 / 导购热销 N≈9 为前三)一次到位,#10/#11 顺手迁。三类显式例外留本地并照 `ORDER_ID_RE` 模范写明理由:① output_guard 输出镜像(刻意稍宽,语义本就不同);② consult 否定闸裸「退货|退款」(词条≠同义,收编反危险);③ LLM prompt 词面散文(不可派生)。`semantic_routes` 例句/阈值族随影子路由归域 C,不入词表之家。
- **防漂移双钉**:每族 ① 派生等价测试(消费面 RE == 从家族常量程序化派生,漏改消费方 CI 即红);② 册外词扫描 lint(pytest 扫源码,`re.compile` 字面命中已入册词条而非常量引用即红)。迁移逐族 parity 快照**逐字节断言**;greeting/refund/cart 包内三块旧样板同批补钉,新册不比旧规矩松。
- **依据**:130 处正则/词表常量散布 16 域,同一词条横跨 slot 建议→引擎快轨→技能 can_handle→执行输出四层各手抄;`intent_registry` 现状只真收 4 族(单一事实源宣言的 1/5 兑现率)。

## 2. 域 B — planner 边界(结论:保图壳、缩入口)

- **保图壳**:exec⇄validator 图环、HITL 挂起/恢复(`job_resume` 骑 run_agent 全图)、重规划基建**全保留**。全退役否决:66 次深规划 LLM 全为测试/演示用户、零真实顾客——既是退役无伤的证据,也是真实复合形状未知的证据。
- **缩入口 = 三闸分三期**(分期见 §6):
  - **闸 2 词表缺口补齐**(二期):单域形状(动作形 11 型 / 约束式导购 20 型)按域 A 新册扩词族,归家技能快轨/咨询直答——收敛性行为变更;
  - **闸 1 上游输出约束**(三期):structured_llm 输出边界(structured_classifier/llm_refine)对**注册表外意图名**(`cart_checkout` 幻觉实证)一律映射/拒收;multi-primary>2 退化(14 天 17 行,其中 9 行在 planner 入口)在进 planner 前拦截;
  - **闸 3 白名单复合链**(四期):真复合仅 5 个句族 → **复合模板表**(意图签名→确定性子任务序列)→ 喂既有 executor⇄validator 环,**零 planner LLM**;HITL 按技能继承(审批闸在技能层,链上照挂)。
- **快轨注册表化(nightly #7)**:声明表「意图签名→子任务模板」收编 7+ 条 if 分支;注册表住 **planner 本地**(单消费方,按域 A「消费方 ≥2」判据不入总册);签名里的词(`_BEST_SELLER_RE` 等)按域 A 迁 registry,planner 变纯消费方。纯重构零行为变化。
- **深规划准入谓词**(spec 可验收条款):`白名单复合模板未命中` **且** `≥2 个已验证动作形意图、跨 ≥2 个域`(或显式连接词+两路动作形提议)方准点火深规划 LLM;**单域输入永不深规划**。谓词不满足走快轨注册表最近模板,表也无则顺序技能链兜底。
- **依据**:14 天 699 threads 深规划仅 66 次(~5%),~49% 单域、~1/5 为上游假复合(词表缺口→LLM 幻觉),max 96.6s;「地址列表」自然实验=同一输入从幻觉复合收敛到规则直通——词表缺口下 LLM 仲裁必误判,确定性直通反而必对。

## 3. 域 C — 级联与观测(结论:Stage 化保留,先补观测再裁撤)

- **结构**:9-Stage 化保留(09-15 刚兑现的红利),三前置(ConfirmationResume/SystemResume/RuleWhitelist,合计 152 行全零 LLM)不归并——归并省行数不省调用。级联域总原则:**先补观测再裁撤**。
- **观测补齐**(契约增列,二期落地):留痕断点 Stage 1/2 与 human_escalation 分支终局不落库,以增列/新表补齐(不动现有 intent_logs 口径);观测满 28 天后,零点火且无独立语义的层才进裁撤名单。VisionParse 只填 ctx,属管道非仪式,不动。
- **零点火分层处置**:`semantic_cache` / `confidence_cascade` / `reformat_guard` 三家**保留**(健康未命中——阈值从未跌破或检出器刚收窄,删=删 nightly 回归面);`profit_ranking_precheck` **补词表**(域 A)后开 28 天死线,仍零点亮即关停(同族 address_manage_precheck 27/27 全救回,实证了此类词表补丁的价值形态)。
- **阈值体系**:不收编统一注册表(缓存命中/重复指纹/路由提议三者语义不同构,强行归一制造假局部性)。0.96 同值三处(semantic_cache 默认参 + consult_fast_path/embedding_anchor 两调用点)收进 semantic_cache 模块具名常量、调用方 import;0.98+数字指纹去重与路由域 [0.7,0.95] 留各自模块顶,互引注释防漂移。
- **consult_shaped_gate 保留**:坏例池消费侧已核实有人读——人工 triage CLI(list/show/triage/draft,`draft` 从候选起草 promptfoo 回归用例)+ scheduler 每 6h digest 执行 90 天 TTL,真实闭环。
- **SemanticIntentRouter 三态 = 继续影子,可判定化**:晋升判据三件套(全部满足方转**正式提议者**进 candidates 常态,不夺终局权):28 天窗口提议 ≥100 ∧ 与最终 winner 一致率 ≥95% ∧ 有独立边际贡献(它提对而 slot_extractor/embedding 都提错的例)。前置 = 低点火根因调查(向量化可得性门控 vs 例句覆盖;现 10 路由 14 天仅 4 提议);根因修复后 28 天仍 <10 提议 → **关停**(死影子也是债)。

## 4. 出局名单(记录否决理由,防 Gen-4 重提)

| 候选 | 否决理由 |
|---|---|
| RouteLLM 式级联 | 选的是模型不是意图,问题错位 |

## 5. 变更局部性验收条款(主尺的可演示验收)

**条款**:域 A 落地后,「加一个新词族/新意图」的代码触点必须收敛到 `intent_registry.py` 单点(+ 新技能注册,若涉新行为),其余消费面全部程序化派生。

**验收演练**(registry-only 落地,假想意图 `gift_card_balance` 查礼品卡余额):

1. 在 `intent_registry.py` 增加词族常量(`_GIFT_CARD_FAMILY`)+ IntentSpec——**只改这一个文件**;
2. 跑派生等价测试,断言 slot 建议/快轨 can_handle/负向豁免各消费面 RE 均自动含新词条;
3. 册外词扫描 lint 通过(无新手抄产生);
4. nightly 矩阵 142 条全绿(证明对既有判定零扰动);
5. 演练 commit 整体 revert,不残留。

1–5 全绿即条款达标;任何一步需要改第二个文件(派生面)即条款不达,域 A 验收打回。

## 7. 回归基线(质量底线的具体化)
