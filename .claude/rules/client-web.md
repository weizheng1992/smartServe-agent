# 客户端客服对话应用规范 (Client Web)

本应用是面向终端消费者的智能客服对话应用，采用 Vite 6 + React 19 SPA 架构，负责多轮会话交互、SSE 实时打字机流式渲染、多模态卡片交互呈现与人工客服协同接管。

## 1. 核心架构与交互规范

### 1.1 SSE 流式打字机与会话恢复 (`useSSEChat.ts`)

- **流式事件总线**：通过 Server-Sent Events (SSE) 接收服务端事件（`token`, `card`, `step_progress`, `takeover_status`, `error`, `done`）。
- **打字机平滑渲染**：文本 Token 实时追加并平滑滚动，避免大段闪烁。
- **自愈式会话恢复**：页面刷新或网络重连时，通过 `threadId` 自动同步加载历史消息与当前执行状态。

### 1.2 多模态交互卡片族谱 (Rich Interactive Cards)

- **卡片渲染引擎**：根据消息中的结构化 JSONB 自动映射渲染卡片（订单详情、退款进度、物流追踪、核销凭证、确认授权等）。
- **卡片交互回调**：卡片内的用户点击动作（如“确认申请”、“选择新地址”）统一封装为特定意图事件回传至对话引擎。

### 1.3 人工坐席协同接管体验

- **接管状态感知**：当 `is_takeover: true` 时，客户端顶部展示“人工客服已介入”提示条，并将消息输入流直接路由至人工坐席通道。
- **无感交接**：人工释放（`release`）接管后，AI 智能体无缝恢复上下文并继续提供服务。

---

## 2. 编码与维护准则

1. **响应式与移动端适配**：界面必须在移动端视口（Mobile Viewport）和桌面端均有优良体验。
2. **轻量与极致加载速度**：避免引入冗余大型外部库，保持首屏加载与打字机响应低于 100ms。
3. **中文文案规范**：所有提示语、加载占位符、错误重试文案统一使用地道标准的中文。
